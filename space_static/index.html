Steel Defect AI

Production-ready ensemble segmentation for industrial surface defect analysis. Built for the Severstal Kaggle competition.

🚀 Run Live Demo on Colab (Free) ⭐ View on GitHub 🤗 Model Weights (HF Hub)

What it does

Upload any steel surface image — get instant defect segmentation with color-coded masks.

🧠

3-Model Ensemble

Averages probability maps from U-Net, FPN, and DeepLabV3+ for robust, accurate predictions.

🔍

Min-Area Filtering

Connected component analysis removes small noise — only real defects are reported.

⚡

FastAPI Backend

Production-grade REST API with automatic weight download from HF Hub on first run.

🎨

Premium Web UI

Glassmorphism dark-mode interface with drag-and-drop image upload and live overlays.
